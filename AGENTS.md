# Android apps

Use the Makefile with JDK17. Never install on a device or replace its Home app without explicit owner approval. App-specific rules remain in apps/fz/AGENTS.md. Preserve both source histories and application IDs. Signing inputs stay in Infisical; never print or commit them. Publish only verified increasing versions with scripts/publish-apk; both original Obtainium feeds receive the identical APK from the canonical android build. Never delete or archive compatibility repositories without explicit approval.
